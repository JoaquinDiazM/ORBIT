# Principios pedagógicos

## Público

Estudiantes con una base mínima de cálculo, álgebra lineal y física clásica, especialmente quienes exploran Ingeniería Eléctrica o comienzan la especialidad.

## Función de la historia

La historia se usa para mostrar la necesidad de nuevas herramientas, no para decorar fórmulas ni construir una galería de grandes hombres.

Cada episodio debe distinguir:

1. observación o problema;
2. evidencia experimental;
3. formulación o modelo;
4. alcance y límites;
5. aplicación posterior.

Las simplificaciones narrativas deben declararse. Las atribuciones históricas deben ser trazables y reconocer procesos colectivos cuando corresponda.

## Orden pedagógico sobre orden cronológico

El grafo de prerrequisitos manda. Una secuencia histórica puede reorganizarse cuando el estudiante necesita antes una herramienta matemática o conceptual.

## Aprender resolviendo

La experiencia debe alternar explicación y práctica. La progresión objetivo es:

```text
observar → imitar → completar → resolver → transferir
```

### Observar

Fenómeno, demostración, datos o contradicción que motive una pregunta.

### Imitar

Ejemplo resuelto que explicita decisiones, no solo operaciones.

### Completar

Problema con pasos parciales y andamiaje decreciente.

### Resolver

Problema de evaluación presentado sin pistas visibles.

### Transferir

Misión que combina herramientas en una tecnología o sistema nuevo.

## Qué debe explicar una solución

- Ley o principio elegido.
- Razón de aplicabilidad.
- Sistema de coordenadas y geometría.
- Convención de signos y orientación.
- Desarrollo matemático.
- Unidades.
- Orden de magnitud.
- Casos límite.
- Interpretación física.

## Autoexplicación

Las actividades deben incluir preguntas como:

- ¿Qué principio utilizaste?
- ¿Qué simetría reduce el problema?
- ¿Qué supuesto sería el primero en fallar?
- ¿Cómo cambiaría la respuesta al duplicar una escala?
- ¿Qué representa físicamente el signo?

## Gamificación subordinada

Los desbloqueos representan competencias reales. No se usarán puntos arbitrarios como sustituto de aprendizaje.

Buenas recompensas:

- una herramienta conceptual;
- una visualización útil;
- una ruta aplicada;
- un transporte coherente con la tecnología estudiada;
- un nuevo personaje que ofrece problemas opcionales;
- una misión integradora.

Evitar:

- tablas de clasificación;
- penalizaciones por velocidad;
- animaciones largas obligatorias;
- contenido académico oculto tras tareas irrelevantes;
- premios que confundan completar con comprender.

## Dos modos de uso

La versión futura debe permitir:

- **Expedición:** progresión narrativa.
- **Atlas:** acceso directo por tema y resultado de aprendizaje.

Un estudiante que repasa para una evaluación no debe quedar atrapado en la narrativa.

## Evaluación del proyecto

La calidad no se mide por tiempo de juego. Métricas útiles incluyen:

- tasa de resolución por tipo de problema;
- errores conceptuales frecuentes;
- capacidad de explicar la elección de una ley;
- transferencia a problemas no idénticos;
- navegación y comprensión de prerrequisitos;
- utilidad percibida antes de evaluaciones;
- accesibilidad.

Cualquier analítica futura debe ser opcional, transparente y respetar privacidad. Para la etapa inicial se prefieren pruebas piloto observadas y cuestionarios externos anónimos.
